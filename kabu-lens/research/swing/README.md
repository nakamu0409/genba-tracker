- 前半・後半の両方で同じ向きだった傾向：高値引けを厳しく見る、反発の合図は「前日の高値を超える陽線」（2日の高値超えより良い）、目標は 3〜4R（2R や目標なしより良い）、急騰が+20%以上の大きすぎるものは悪い（後半 −0.11R）。押しの深さ・日数・地合いは前半と後半で向きが変わった。

- 前半5年 +15.6%/年、後半5年 +19.3%/年（全部入り）。両方プラス。
- **いちばん大きな弱点：企業の行動の上乗せは1回 +0.4〜0.5% と薄い。** 寄りと引けの値段が毎回0.1%ずつ不利になるだけで年率 +9.4%、0.3%ずつで +2.9% まで落ちる。寄指（寄りの値段で約定）と引成（引けの値段で約定）を使い、値段をずらさないことが前提。
- 甘く出ている点：銘柄は今も上場している株だけ（倒産・上場廃止が入っていない）。自社株買いの「良い条件」は同じ10年で見つけた（使わずに全部買っても +19.2%/年 なので、影響は小さい）。

### 寄指の上限を広げたら（`GAP=1 node ... study_portfolio.mjs`、2026-11-20）
テリロジー（寄り+2%超で見送り→その後+14%）を受けて確かめた。全部入りの口座10年の年率：上限+2% +20.7%（前半+15.6%・後半+19.2%）、+3% +14.5%、+5% +20.1%、+10% +27.9%（前半+23.6%・後半+17.2%）、+30% +17.0%。
- 上げても下げても一定の向きが無い（+3%で悪化、+10%で改善、+30%でまた悪化）。この程度の差は偶然の範囲。1回ごとの平均は窓が大きいほど小さい（+2%以内+0.43%、+2〜5% +0.16%、+5〜10% +0.35%、+10%超 −0.22%。寄り→引け、全体比ではない）。
- 決まり（+2%）は変えない。本番の記録（events。見送りも全件）で窓+2〜5%の成績がたまってから考える。
