# スイングの売り方の検証（2026年11月19日）

`study_exits.mjs`。1時間足（約1,110銘柄・2023-12〜2026-11）から作った日足で、analyze の買い候補（通過）46,232回を、売り方だけ変えて比べた。翌日の始値で買う（終値の+2%を超えて寄ったら買わない）、損切りは候補の stop、逆指値は0.1%不利。候補ごとに独立に数える（重なりあり）。比べる相手（TOPIX）は入れていないので相対強さの条件は効いていない。今の売買の多い銘柄だけなので、上場廃止などの生き残りの偏りがある。

- **目標4R は3年のうち2年で今より良く、残りの1年もほぼ同じ**。いちばん無理のない改善。
- 2024年はどの売り方でもマイナス。売り方より相場の向きの影響が大きい。

## 比べる相手と地合い
- どの日に買っても（5日ごと、損切り＝終値−ATR×2、今の売り方）：+0.34R。**買い候補（+0.33R）は、どの日に買うのとほぼ同じ**（この検証では、相対強さの条件が効いていない点に注意）。
- 地合い（25日線の上にいる銘柄の割合）で分けても、年ごとに向きがばらばらで、使える分かれ目は見つからなかった。

## 強い株を少数持ち続ける（モメンタム）と、市場全体を持つのを比べた（2026年11月19日）

- 少数の強い株に集中すると、上げ相場の年（2025年）は大きく増えるが、それ以外の年に大きく減り、ほとんどの組み合わせで市場全体に負けた。一番下げたときは −60〜−90%。
- **市場全体を持ちっぱなしにするのが、下げも小さく、ほとんどのやり方より増えた**。短い売買で市場全体に勝つのは難しい。

## 自社株買いの発表のあと（2026年11月19日）— 上乗せはあるが、最初の数字は甘かった（下の訂正を見ること）

`fetch_irevents.mjs`（IR BANK の適時開示一覧、約1,400銘柄・2013年〜）と `study_buyback.mjs`。表題に「自己株式」「取得」「決定／事項」があるもの（取得状況・結果・終了・完了の報告は除く）。15:00以降の発表は翌営業日、場中は当日を反応日とする。その日の売買代金1億円以上。張り付きの日は除く。

| 決算と別の日の発表（1,990回） | 自社株買い | どの日でも |
|---|---|---|
| 翌朝の寄りで買い、その日の大引けで売る | **+0.70%**（中央+0.51%、勝率57%） | −0.02% |
| 寄りで買い、損切り（前日終値−ATR×2）で5日 | +0.20R | +0.01R |
| 同じく20日 | +0.28R（前半+0.28／後半+0.27） | +0.08R |
| 同じく目標4R・40日 | **+0.35R**（前半+0.28／後半+0.40） | +0.13R |
| 超過（同じ日に全銘柄を寄りで買った平均との差）20日 | +0.85%（11年のうち11年プラス） | — |

- 1日目（寄り→大引け）は、2017〜2026年のどの年もプラス（+0.43〜+1.04%）。直近の年ほど大きい。
- 翌朝の窓（寄り ÷ 発表前の終値）が 0〜2% のときが一番良い（1日目 +1.20%）。窓が2%以上だと小さくなる（+0.2%台）。窓がマイナスでも +0.83%。
- 大引けで買うと、20日の超過はほぼ0（+0.17%）。**上乗せのほとんどは発表の翌日の寄りから引けまでに出る**。
- 決算と同じ日の発表は弱い（20日 +0.47%、プラスの年 6/10）。ToSTNeT（立会外）での取得は34回でマイナス。
- 回数：決算と別の日の発表は直近1年で351回（月に約29回）。発表のあった日は1日あたり平均約2件。
- 注意：今の売買の多い銘柄だけ（生き残りの偏り）。寄り付き・大引けは板寄せなので、寄成・引成ならその値段で約定する（値段のずれは小さい）。まだ本番では確かめていない。

### 訂正（同じ日の夜）：場中の発表を数えていた

最初の版は、15:00より前（場中）の発表も「その日の寄りで買う」として数えていた。場中の発表は寄りの時点では知りようがなく、その日の値上がりを先取りしていたので、成績が甘く出た。15:00以降の発表だけで数え直した（study_buyback.mjs、study_buyback_filters.mjs）。

| 決算と別の日・15:00以降の発表 | 回数 | 翌日の寄り→大引け |
|---|---|---|
| 全部 | 1,597 | +0.30%（中央+0.25%、勝率54%）。どの日でも −0.02% |
| **寄指（寄りが前日の終値×1.02以下）で買える日** | 734 | **+0.43%（前半+0.28／後半+0.54）、勝率56%** |
| 窓 +2〜5% | 423 | +0.15% |
| 窓 +10%超 | 95 | −0.21% |

年ごと（1日目）：2017 +0.07、2018 −0.06、2019 +0.24、2020 +0.31、2021 +0.06、2022 +0.62、2023 +0.42、2024 +0.25、2025 +0.39、2026 +0.43。損切りつきで持つと 目標4R・40日 +0.25R（どの日でも +0.13R）。

**寄指で買える日（734回）を、さらに分けた（前半・後半の両方で効くもの）**
- 久しぶり（1年以内に自社株買いの決定が無い）+0.61%（前+0.46／後+0.75） ／ くり返し +0.25%
- 発表が 15:00〜15:29 +0.60%（前+0.43／後+0.86） ／ 15:30以降 +0.32%
- 25日線から −5%未満 +0.89% ／ +5%以上 +0.16%
- 良い条件（久しぶり・15時台前半・25日線の下）の数：0 → −0.06%（133回）、1 → +0.36%（304回）、**2 → +0.70%（237回、前+0.59／後+0.81、勝率62%）、3 → +0.78%（60回、勝率63%）**
- 使い方：良い条件が0の日は見送り。数の多い順に買う（`buybackScore`、`--buyback` の score）。
