---
description: 【場中の判定】5分足から今の地合い・VWAP・支えと壁・買い場かどうかを出し、記録帳にチャートを残す
argument-hint: <銘柄名かコード> [今の値段]（複数可。例: 7203 3100 6758）
---

対象: $ARGUMENTS

場中（9:00〜15:30）に、5分足から「今どういう流れか」「買うならどこか」を見る。判定はスクリプトに任せ、自分で条件を足したり緩めたりしない。

1. 銘柄名しか無いときは、記録帳に同梱の universe-wide.json か株探でコードを確かめる（分からなければ本人に聞く）。
2. `node .claude/scripts/kabu-lens.mjs --intraday <コード>[:今の値段] [...]` を実行する（例 `--intraday 7203:3100 6758`）。
   - 本人が今の値段を添えたとき（楽天の画面の値段＝リアルタイム）は、必ず `:値段` を付ける。遅れた5分足の後ろに今の値段をつないで判定し直す（結果に live_price と delayed_price が出る）。
   - 本人が楽天のチャートや板のスクショを送ってきたら、画像から今の値段・その日の高安・板の買いと売りの厚さ（気配の株数）を読み取り、今の値段は `:値段` で渡す。板は「買いが厚い／売りが厚い」と、近い大きな売り板・買い板の値段を1行で添える（板は判定に入れていない参考の情報だと言う）。読み取れない数字は推測しない。
   - 値段が無いときは、15〜20分前の判定であることをはっきり言い、「今の値段を教えてもらえれば判定し直す」と添える。
3. 1銘柄ごとに、短く伝える。
   - 何時時点か（time）と、**株価は15〜20分遅れ**であること。楽天の画面の今の値段と合わせて見るよう添える。
   - 今の値段・前日比・始値からの騰落・VWAP（今日の平均の買値）との位置。
   - 場中の地合い（regime）：TREND_UP＝上昇、TREND_DOWN＝下降、CHOPPY＝もみ合い、PANIC＝急落。日足の向き（daily_trend：25日線の上で上向きなら UP）。
   - 近い支え（supports）と壁（resistances）を2つずつ。
   - 合図（signal）と理由（reasons）をそのまま。TAKE＝買い場、WAIT＝待つ、SKIP＝見送り。
   - TAKE なら、指値の目安（limit）と場中の損切りの目安（stop_intraday。買値から1%以上離してある。狭すぎるとふだんの揺れで切られるため）。売り方は「買ったらすぐ stop_intraday に逆指値、届かなければ大引けで売る（楽天の引成）。途中で利確や早売りはしない」（過去60日の検証で一番バランスが良かった。30分後・60分後に売ると上乗せが消える）。持ち越すなら損切りは /kau の値段（日々の値幅の2倍）を使うこと。
   - 「合図はまだ試し中。買い場は 10:30〜13:00 で、伸びすぎ・値動きの荒い株・25日線から離れすぎを除いたもの（過去34日で平均より+0.18%、勝率58%。小さい上乗せで、外れる日も多い）。毎晩全銘柄で本番の成績を記録中」と1行添える。形は買い場でも条件で外れたとき（raw_take があって signal が WAIT）は、外れた理由をそのまま伝える。marks に RECLAIM_PM があれば「後場に VWAP を取り戻した形（持ち越し向き・試し中）」と添える。 marks に LOW_STRONG_CLOSE があれば「低位株の強い引け（試し中）。15:00〜15:25に買い、翌朝の寄り前に利確+5%の指値と損切り−8%の逆指値（逆指値付通常注文）、どちらも無ければ翌日13時に売る。張り付いて買えない日を除いた検証は74回・平均+1.6%・勝率58%で、上乗せは小さい。株数は損切り−8%で /kau の上限に収める」と添える。low_group が true（低位株か荒い株）なら、「この種類の株は、場中の買い場の形でも成績が出ていない（検証）。平均すると翌日まで持つと不利」と1行添える。
4. 記録帳（Artifact の list で題名「トレード記録帳」を探す）の collection "intraday" に1銘柄1件 set する。doc_id は「<date>-<コード>-<time の : を除いた4桁>」。項目：結果の JSON の code, name（日本語の銘柄名に置き換える。Yahoo の名前は英語のため）, date, time, price, open, vwap, from_prev_pct, regime, daily_trend, supports, resistances, signal, kind, reasons, limit, stop_intraday, bars（チャート用。そのまま）と、final: false、createdAt。夜の記録が「大引けまで」「翌日まで」の答えを足す。
5. 買いたいと言われたら、必ず /kau を通す（場中の判定は /kau の代わりにならない）。
