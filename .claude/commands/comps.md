---
description: 【ステップ4 値付け】同業他社とPER・EV/EBITDA・PBRを並べて割安か割高かを比べる
argument-hint: <企業名> [比較する同業2〜3社]（決算短信を添付してもOK）
---

対象と比較先: $ARGUMENTS

1. 数字を集める
   - 添付の決算短信があればそれを使う。なければ WebSearch / WebFetch で各社の最新の決算短信・株価を集める。
   - 同業が指定されていなければ、事業内容が近い2〜3社を選び、選んだ理由を書く。
   - 各社について: 株価（取得日）、発行済株式数（自己株式除く）、当期純利益（今期の会社予想。なければ直近の実績と明記）、純有利子負債（有利子負債 − 現金）、EBITDA（営業利益 + 減価償却費）、純資産、営業利益の伸び率。
   - 単位をそろえる（金額が億円なら株数は億株）。
2. 計算はスクリプトで行う（暗算しない）
   - `stock-research/<企業名>/comps-input.json` を次の形で書く:
     ```json
     { "target": "さくら食品",
       "companies": [
         { "name": "さくら食品", "price": 1000, "shares": 1.0, "netIncome": 10, "netDebt": 20, "ebitda": 25, "equity": 80, "profitGrowth": 0.15 }
       ] }
     ```
   - `node .claude/scripts/stock-calc.mjs comps stock-research/<企業名>/comps-input.json` を実行し、出力の表をそのまま使う。
3. 読み解き（初心者向けに）
   - 対象企業は同業より割安か割高か。成長率の差を踏まえると妥当か（「伸びているのにPERが低い＝まだ評価されていない可能性」など）。
   - 倍率が違う理由として考えられること（事業の違い、一時的な利益など）。
4. 結果を `stock-research/<企業名>/comps.md` に保存する（入力の出典と取得日を含める）。

売買推奨はしません。次は /dcf で理論株価を確認するよう案内してください。
