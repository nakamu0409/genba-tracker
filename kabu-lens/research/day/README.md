# 急騰した株に昼から飛びついたらどうなるか

「前場に5%以上上げた株を、後場の寄り付きで買って、引けで売る」を過去のデータで調べた。2026年11月16日。

```bash
node kabu-lens/research/day/fetch_intraday.mjs   # 売買の多い約1,400銘柄の、1時間ごとの株価 約3年分（market.json が必要）
node kabu-lens/research/day/study_day.mjs        # 特徴ごとの集計
node kabu-lens/research/day/score_day.mjs        # 危険度スコアの検証
```

- 銘柄: 2026年11月16日の前場で売買代金5,000万円以上だった、東証プライム・スタンダード・グロースの1,442銘柄
- 期間: 2023年11月〜2026年11月。前半と後半に分けて、両方で同じ傾向かを確かめた
- 回数: 前場+5%以上は 23,240回

## わかったこと

1. **全体では、飛びついても儲からない。** 平均は前半 0.00%、後半 −0.13%。勝率は47%。
2. **「これなら勝てる」という特徴は無かった。** どの分け方でも、平均がはっきりプラスの組は無い。
3. **「これは危ない」という特徴はあった。** 後場に3%以上下げる割合が、前半・後半の両方で高かったもの:
   前場で+15%以上の急騰／株価300円未満（特に100円未満）／出来高が普段の30倍以上／高値から5%以上下げている／直前5日で+15%以上上げている／普段から1日5%以上動く
4. 普段の売買代金や、上げのうち窓開けが占める割合は、関係が無かった。

## 危険度スコア（`chaseRisk`）

上の「危ない特徴」にだけ点を付けた合計（0〜100）。

| 危険度 | 点数 | 全体に占める割合 | 平均 | 勝率 | 3%以上下げた割合 | 5%以上下げた割合 | 悪いほうの1割 |
|---|---|---|---|---|---|---|---|
| 低 | 0〜14 | 75% | +0.02% | 49% | 4% | 1% | −1.9%以下 |
| 中 | 15〜34 | 17% | −0.10% | 44% | 13% | 4% | −3.5%以下 |
| 高 | 35以上 | 8% | −0.86% | 39% | 27% | 17% | −7.1%以下 |

点数が上がるほど大きな下げが増えることは、前半・後半の両方で確かめた。

**注意**: 危険度が「低」でも、平均はほぼ0%で、勝率は半分に届かない。「安全」や「買ってよい」という意味ではなく、「大きくやられる割合が低い」という意味。点数の区切りは全期間を見て決めたので、実際はこれより少し甘く出ている可能性がある。銘柄は今の時点で売買の多いものを選んでいる。手数料・値段のずれは入っていない。

# 急落した株を昼に買ったらどうなるか

「前場に5%以上下げた株を、後場の寄り付きで買って、引けで売る」を同じデータで調べた。2026年11月16日。

```bash
node kabu-lens/research/day/study_down.mjs    # 特徴ごとの集計
node kabu-lens/research/day/study_down2.mjs   # 相場全体が崩れた日と、その株だけ下げた日を分ける
node kabu-lens/research/day/score_down.mjs    # 危険度スコアの検証
```

- 回数: 前場−5%以下は 19,035回。うち約6割（11,242回）は、同じ日に50銘柄以上が急落した「相場全体が崩れた日」（68日）に集中している。

## わかったこと

1. **反発を狙える特徴は無かった。** その株だけ下げた日は、平均 −0.06%、勝率44%。「下げすぎだから戻る」とは言えない。
2. **相場全体が崩れた日は、日によって結果が正反対になる。** 前半は平均 −1.6%（さらに崩れた）、後半は +0.5%（戻した）。その日の特徴からは読めない。
3. **さらに崩れやすい特徴はあった**（その株だけ下げた日の、前半・後半の両方で）: 株価100円未満／安値からすでに5%以上戻している／直前5日で+30%以上上げていた／直前5日で15%以上下げている／普段から1日8%以上動く。
4. 下げ幅の大きさ、出来高、窓開けの割合は、はっきりした関係が無かった。

| 低 | 0〜14 | 71% | −0.05% | 46% | 4% | 1% | −2.1%以下 |
| 中 | 15〜34 | 21% | −0.02% | 42% | 12% | 4% | −3.2%以下 |
| 高 | 35以上 | 8% | −0.27% | 36% | 23% | 10% | −5.0%以下 |

**注意**: 「低」は「下がっているけど安全」という意味ではない。平均はほぼ0%で勝率は半分に届かない。「さらに大きく崩れる割合が低い」だけ。材料（決算・下方修正など）は過去のデータが無く、検証に入っていない。

# 場中の5分足の合図は当たるか（2026年11月18日）

```
node kabu-lens/research/day/fetch_5m.mjs <universe-wide.json>   # 約1,150銘柄の5分足 直近60日分（Yahoo の上限）→ five.json
node kabu-lens/research/day/study_5m.mjs                        # intradayView（/bachu と同じ判定）を過去に当てはめる
```

- 判定は 9:30〜14:30 の30分ごと。その時刻までに出来た足だけを使う。株価は約20分遅れで見えるので、買うのは「判定の時刻＋20分」の足の始値。
- 結果は、同じ日・同じ時刻の全銘柄平均との差（全体比）。1,108銘柄・33日・約29万回。
- 33日しかないので、前半と後半に分けて同じ向きかと、中央値も見た。

| TAKE BREAKOUT | 882 | +0.14% | +0.11% | 件数が少なく、後半に偏る |

- **TAKE の上乗せは、あっても0.1〜0.2%ほど。** 売買の手数料と値段の開き（スプレッド）でほぼ消える大きさで、これだけで勝てるものではない。使い方は「買うと決めた株の、買う時間と値段を選ぶ」補助にとどめる。
- 10:30〜11:00 の判定はいちばん安定していた（前半・後半・中央値のどれでもプラス）。昼前に入る形は、続けて記録して確かめる。
- 場中の地合い（上昇・下降）は、大引けまでの向きを少しだけ当てる（±0.05〜0.07%）。下降中（TREND_DOWN）に買わないのは理にかなう。
- 急騰（前日比+8%以上）を場中に追いかけると、その日の大引けまでは平均より悪い（決めごと「急騰を追いかけない」と同じ向き）。ただし**翌日は平均より+1%ほど良かった**。昼の急騰株の研究（後場だけを見た）とは別の結果で、33日だけなので、まだルールは変えない。続けて確かめる。
- 「チャートを見て当てる」合図は、ほかの検証（窓あけ・決算・急騰）と同じく、単独で大きく勝てるものは見つからなかった。

データ（five.json）は大きいのでコミットしない。

## 本番の記録（2026年11月18日の分から）

- 毎晩の「候補の記録」が `--intraday-wide` で、前の営業日の場中の判定を約1,150銘柄で再現し、記録帳の `settings/intraday_wide_stats` に足していく（1日約9,000回）。
- 上の検証（60日）に使ったのは 11/17 までなので、11/18 からは検証と重ならない本番の数字になる。
- 20日分ほどたまったら、検証と同じ向きが続いた組（たとえば 10:30〜11:00 の買い場、後場の VWAP 奪回の翌日）だけを合図として残し、向きが合わない組は外す。
- ゆるめた案（下げたあとの VWAP 奪回、もみ合いの押し目）も試したが、その日のうちの成績は今の合図より良くならなかった。後場の VWAP 奪回だけ、翌日まで持つと前半・後半とも+0.2%ほど良かったので、目印（RECLAIM_PM）として記録している。

## 買い場の絞り込み（2026年11月19日）

買い場（TAKE）約1万4千回について、特徴ごとの成績を前半（9/30〜10/23）と後半（10/26〜11/18）に分けて見た（試したスクリプトは記録のみ。判定は intradayView に入れた）。

- **どちらの期間でも悪かった形を外した**：判定の時刻が 10:30〜13:00 以外（10:00 と 13:30 以降は平凡）、VWAP から+1.5%以上離れている、始値から+4%以上か−1%未満、短い平均（9本）が長い平均（20本）より0.5%以上上（伸びきり）、1日の値幅の目安が株価の4%以上（荒い株）、前日終値が25日線から+10%以上。形は買い場でも、これに当たれば「待つ」にして理由を出す（`raw_take` に元の形を残す）。
- 結果（同じ期間なので甘めの数字）：買い場は 14,112回 → 4,310回。大引けまでの全体比 +0.09% → +0.18%（前半+0.14・後半+0.23、中央値+0.12）、勝率 52% → 58%、翌日まで +0.04% → +0.28%。
- **VWAP を割ったら手放す**は、大引けまで持つより悪かった（+0.16% → +0.08%）。一度 VWAP を割ってから戻す株が多く、勝ちを早く切ってしまう。入れない。場中の損切りの目安で手放すのもほぼ同じで、良くならない。
- **地合い**（その時刻に VWAP の上にいる銘柄の割合、全銘柄の始値からの平均、上昇と下降の銘柄の差、30分の変化）は、前半と後半で向きが逆になり、悪い日を前もって避ける目安にはならなかった。11/17・11/18 のように、ほぼすべての買い場が外れる日がある（34日のうちプラスの日は約半分）。だから1回の株数と損切りが守りになる。
- 本番の確かめ：毎晩の自動記録（`settings/intraday_wide_stats`）に、絞り込み後（TAKE）と絞り込む前（TAKE_RAW）を並べて記録する。20日ほどで、絞り込みが本番でも効くかが分かる。

## 低位株・値動きの荒い株だけで探す（2026年11月19日）

対象：前日終値500円未満か、1日の値幅の目安が株価の4%以上（550銘柄・約8万5千回の判定）。比べる相手は同じ時刻の「同じ種類の株」の平均。

- **場中のどの形も、その日の大引けまでの差は±0.1%ほど**で、前半と後半で向きもそろわない。ふつうの株で効いた押し目・高値抜けも、この種類の株では効かない（買い場の形 2,783回で+0.03%、翌日まで−0.24%）。
- 14:50 に買って翌日まで持つと、**全体では不利**（翌日の大引けまで−0.44%、前半・後半とも負け）。翌日の寄りも弱い（−0.26%）。
- その中で、**前日比+10〜20%・VWAPの上・今日の値幅の上3割**（強い引け）だけは、翌日の大引けまで+1.18%（前半+0.19・後半+1.75、中央値+1.52）。ただし112回・26日だけで、翌日に途中で−3.4%ほど下げるのがふつう。目印 LOW_STRONG_CLOSE として記録して、本番で確かめる。
- 前日比+5〜10% は、前半と後半で向きが逆だった。+20%以上は件数が少なすぎる。
- 参考：ふつうの株は、14:50 に買って翌日の寄りで売ると全体比+0.10%（前日比+5〜10%なら+0.96%、ただし前半はマイナス）。
- 毎晩の自動記録に LOW_ALL・LOW_TAKE_RAW・LOW_STRONG_CLOSE の組を足した。
