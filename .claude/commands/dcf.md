description: 【ステップ4 値付け】DCF法で理論株価・安全域・感応度表を出す
argument-hint: <企業名>（決算短信・有報を添付してもOK）
---

対象: $ARGUMENTS

1. 前提を集める（添付資料を優先。なければ WebSearch / WebFetch）
   - 直近のフリーキャッシュフロー（FCF = 営業CF − 設備投資）。1年だけだとブレるので、過去3年の平均や正常化した値も検討する。
   - 発行済株式数（自己株式除く）、純有利子負債（有利子負債 − 現金。リース負債の扱いも明記）、今の株価（取得日）。
2. 前提を決めて、**それぞれ理由を初心者にもわかるように説明する**
   - 5年分の成長率（会社の中期計画、過去の成長率、業界の伸びを根拠に。だんだん下げるのが基本）
   - 割引率（WACC。日本株なら6〜9%程度が目安。リスクが高い会社ほど高く）
   - 永久成長率（0〜1.5%程度。日本の名目成長率を大きく超えない）
3. 計算はスクリプトで行う（暗算しない）
   - `stock-research/$ARGUMENTS/dcf-input.json` を次の形で書く（単位をそろえる: 金額が億円なら株数は億株）:
     ```json
     { "baseFcf": 50, "growthRates": [0.08, 0.07, 0.06, 0.05, 0.04],
       "wacc": 0.07, "terminalGrowth": 0.01, "netDebt": 100, "shares": 0.5, "price": 1000 }
     ```
   - `node .claude/scripts/stock-calc.mjs dcf stock-research/$ARGUMENTS/dcf-input.json` を実行し、理論株価・安全域・感応度表をそのまま使う。
4. 読み解き
   - 安全域が大きい（目安 +30%以上）→ 買う候補として有力。小さい・マイナス → 高値づかみの可能性。株価が下がるまで待つ選択肢を示す。
   - 感応度表を見て「前提が少し悪い方に外れても割安か」を確認する。
   - 継続価値の比率が高すぎる場合は、結果が前提次第であることを強調する。
5. `stock-research/$ARGUMENTS/dcf.md` に前提・理由・出典・結果を保存する。

前提はAIの仮置きであり、自分で根拠を確かめて調整すべきことを最後に伝える。売買推奨はしません。
