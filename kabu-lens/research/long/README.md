# 業績の勢いは「少し長期」の買い時になるか（2026年11月19日）

```
node kabu-lens/research/long/fetch_fin.mjs <universe-wide.json>   # 株探の決算ページ（通期と四半期の業績・発表日）→ fin.json
node kabu-lens/research/long/study_momentum.mjs                  # 発表の翌営業日の始値で買い、20・60営業日後と比べる（hour.json も使う）
```

- 株探で無料で見られる四半期は直近8つなので、前年と比べられるのは直近4つの発表（2025-11〜2026-11、861銘柄・3,418回）。1年分しかない。
- 比べる相手は、同じ日に買った全銘柄の平均（全体比）。

| 発表の中身 | 回数 | 60日後の全体比 | 前半／後半 |
|---|---|---|---|
| 全部 | 3,418 | −0.99% | −0.59／−1.80 |
| 営業益+20%以上・売上+10%以上（強い決算） | 906 | **−3.82%** | −1.43／−6.96 |
| 同・2回以上続けて増益 | 620 | −6.34% | −4.36／−7.67 |
| 前年が赤字（比べられない＝立ち直り） | 459 | **+3.98%** | +6.32／−0.05 |
| 営業益−20%以下・売上マイナス | 234 | +0.12% | −1.24／+4.09 |

- **強い決算のあとに買っても、60日は平均より悪かった**（前半・後半とも）。好業績は発表前から株価に入っていることが多く、期待が高いぶん崩れやすいと考えられる。
- 立ち直り（前年赤字）は良かったが、後半は±0で安定していない。
- 翌朝の反応（窓）で分けても、はっきりした差は無い。
- 1年分・生き残りの偏りありなので、結論ではない。/mite の「少し長期」は判定を出さず、業績の事実と、この検証の結果を参考として示す。
- 長い期間の四半期データ（有料か IR BANK の別ページ）が取れれば、確かめ直す。
