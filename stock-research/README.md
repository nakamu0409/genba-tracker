# 株リサーチ（高値づかみを防ぐ5ステップ）

Claude Code でこのリポジトリを開き、次のコマンドを打つだけで5ステップが動きます。
ChatGPT 担当だった「探す・読む・疑う」も、Claude Code の Web 検索で同じことができます。
各銘柄の結果はこのフォルダ（`stock-research/<銘柄名>/`）に保存され、あとから答え合わせに使います。

| ステップ | コマンド | やること |
| --- | --- | --- |
| 1. 探す | `/theme データセンター電力` | テーマの恩恵銘柄を直接・間接に分けて10社 |
| 2. 読む | `/kessan さくら食品` | 最新の決算短信を探し、前年比・進捗率・良い点・懸念点を整理（PDF添付も可） |
| 3. 疑う | `/bear さくら食品` | 空売りアナリスト役で「今買うべきでない理由」5つ＋懸念が外れる条件 |
| 4. 値付け | `/comps さくら食品 もみじ製菓 つばき食品` | PER・EV/EBITDA・PBR を同業と比較 |
| 4. 値付け | `/dcf さくら食品` | 理論株価・安全域・感応度表 |
| 5. 記録 | `/thesis さくら食品` | 買う理由と売る条件を記録・更新 |
| 5. 記録 | `/catalysts さくら食品` | 決算発表日などのイベント一覧 |
| 5. 記録 | `/earnings さくら食品` | 決算が出たら仮説どおりか答え合わせ |
| まとめて | `/stock-research さくら食品` | 2〜5を通しで実行 |

- 計算（PER・DCF・感応度表）は AI に暗算させず `node .claude/scripts/stock-calc.mjs` で確定させます。
- コマンドの中身は `.claude/commands/*.md`。プロンプトを自分好みに直せます。
- ⚠️ このフォルダはリポジトリにコミットされます。リポジトリが公開なら、保有銘柄などの記録が見えてしまう点に注意してください。

AIは株価の未来を当てません。数字は一次資料で裏を取り、前提は自分で確かめ、最後の判断は自分で行ってください（本機能は特定銘柄の推奨ではありません）。
