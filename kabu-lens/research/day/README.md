# 急騰した株に昼から飛びついたらどうなるか

「前場に5%以上上げた株を、後場の寄り付きで買って、引けで売る」を過去のデータで調べた。2026年11月16日。

```bash
node kabu-lens/research/day/fetch_intraday.mjs   # 売買の多い約1,400銘柄の、1時間ごとの株価 約3年分（market.json が必要）
node kabu-lens/research/day/study_day.mjs        # 特徴ごとの集計
node kabu-lens/research/day/score_day.mjs        # 危険度スコアの検証
```

- 銘柄: 2026年11月16日の前場で売買代金5,000万円以上だった、東証プライム・スタンダード・グロースの1,442銘柄
- 期間: 2023年11月〜2026年11月。前半と後半に分けて、両方で同じ傾向かを確かめた
- 回数: 前場+5%以上は 23,240回

## わかったこと

1. **全体では、飛びついても儲からない。** 平均は前半 0.00%、後半 −0.13%。勝率は47%。
2. **「これなら勝てる」という特徴は無かった。** どの分け方でも、平均がはっきりプラスの組は無い。
3. **「これは危ない」という特徴はあった。** 後場に3%以上下げる割合が、前半・後半の両方で高かったもの:
   前場で+15%以上の急騰／株価300円未満（特に100円未満）／出来高が普段の30倍以上／高値から5%以上下げている／直前5日で+15%以上上げている／普段から1日5%以上動く
4. 普段の売買代金や、上げのうち窓開けが占める割合は、関係が無かった。

## 危険度スコア（`chaseRisk`）

上の「危ない特徴」にだけ点を付けた合計（0〜100）。

| 危険度 | 点数 | 全体に占める割合 | 平均 | 勝率 | 3%以上下げた割合 | 5%以上下げた割合 | 悪いほうの1割 |
|---|---|---|---|---|---|---|---|
| 低 | 0〜14 | 75% | +0.02% | 49% | 4% | 1% | −1.9%以下 |
| 中 | 15〜34 | 17% | −0.10% | 44% | 13% | 4% | −3.5%以下 |
| 高 | 35以上 | 8% | −0.86% | 39% | 27% | 17% | −7.1%以下 |

点数が上がるほど大きな下げが増えることは、前半・後半の両方で確かめた。

**注意**: 危険度が「低」でも、平均はほぼ0%で、勝率は半分に届かない。「安全」や「買ってよい」という意味ではなく、「大きくやられる割合が低い」という意味。点数の区切りは全期間を見て決めたので、実際はこれより少し甘く出ている可能性がある。銘柄は今の時点で売買の多いものを選んでいる。手数料・値段のずれは入っていない。
