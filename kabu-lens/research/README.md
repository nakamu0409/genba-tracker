# ルールの検証

買い候補のルールが過去にどうだったかを確かめるためのスクリプトです。

```bash
node kabu-lens/research/fetch.mjs   # 約170銘柄の日足10年分を bars.json に保存（数分）
node kabu-lens/research/study.mjs   # ルールと売り方の組み合わせを検証
```

クラウド環境では、先頭に `NODE_USE_ENV_PROXY=1` を付けて実行します。

## 検証のしかた

- 銘柄: `codes.json` の大型株（2026年11月時点で選んだもの）
- 期間: 2017年〜2026年。前半（〜2021年）で良かったものを選び、後半（2022年〜）でも通用するかを見る
- 買い方: 候補が出た翌営業日の始値（終値より+2%超なら見送り）。同じ銘柄で保有中は次の候補を数えない
- 基準: 「どの日でも買った場合」（15営業日おき）と比べる

## 2026年11月15日の結果

| | 回数 | 勝率 | 1回あたり |
|---|---|---|---|
| 今のルール・目標2倍・20営業日 | 9,017 | 42.0% | +0.066R |
| 今のルール・目標3倍・40営業日 | 6,902 | 34.1% | +0.116R |
| どの日でも買う・目標3倍・40営業日 | 23,212 | 35.6% | +0.114R |

わかったこと:

1. **買い候補のルールは、「どの日でも買う」とほぼ同じ成績だった。** 買う日の選び方に、はっきりした優位は見つからなかった。
2. **成績は年で決まる。** どのルールでも 2017・2023・2025年はプラス、2018・2022年はマイナス、ほかの年はほぼゼロ。
3. **利益を長く伸ばす売り方は、前半・後半の両方で良かった。** 目標2倍・20営業日より、目標3倍・40営業日や、値幅の3倍で追いかける損切りのほうが1回あたりが大きい。勝率は35%前後に下がる。
4. **「値動きが荒い局面は見送る」は外さない。** 前半は見送って正解（−0.11R）、後半は逆（+0.18R）で、一貫しなかった。
5. **地合い（TOPIXが200日線の上）で絞っても、一貫した改善はなかった。**

注意: 銘柄は今の時点で大きく売買されているものを選んでいるので、成績は実際より良く出やすい。手数料・税・注文のずれは入っていない。過去の結果は将来を保証しない。

## 別の考え方の検証（study2.mjs / study3.mjs / study4.mjs）

同じデータで、日足だけで試せる別の方法を調べた。「1回」は1回の売買の平均損益（%）。

| 方法 | 前半（〜2021年） | 後半（2022年〜） | 判定 |
|---|---|---|---|
| 逆張り: 200日線の上で RSI(2)<10 を買い、5日線の上で売る（損切り ATR×3） | +0.13%（勝率65%） | +0.15%（勝率65%） | 一貫しているが、1回が小さすぎる |
| 好材料の窓開け: 窓+2%・出来高2倍・陽線で高値引け → 40営業日（損切り ATR×2） | +1.19%（446回） | +2.33%（626回） | **採用して追跡する** |
| 52週高値の更新を買う | −0.26% | +0.70% | 一貫しない |
| 過去6か月で強い銘柄の上位10%を1か月持つ（平均との差） | +1.10% | −0.26% | 一貫しない |
| 過去1か月で弱い銘柄の下位10%を1か月持つ（平均との差） | +0.42% | −0.34% | 一貫しない |
| 過去5日で弱い／強い銘柄を5日持つ（平均との差） | ほぼ0 | ほぼ0 | 効果なし |
| 基準: いつでも買って40営業日（損切り ATR×2） | +0.35% | +0.85% | — |

好材料の窓開けについて:

- 窓の大きさ（2〜5%）と出来高（1.5〜4倍）の20通りの組み合わせすべてで、前半・後半ともプラスだった。特定の数字に合わせた結果ではない。
- 長く持つほど良かった（5日・10日は前半ほぼ0、40日以上でプラス）。
- 年別では10年のうち8年がプラス、2018年と2022年がマイナス。
- 勝率は35〜40%。少ない大きな勝ちで全体がプラスになる形。
- **株価2,200円前後までの60銘柄に限ると弱い。** 2018〜21年 +2.13%、2022〜23年 +0.09%、2024〜26年 +1.41%（回数が少なく、偶然と区別しにくい）。それ以外の銘柄では3期間とも基準を上回った。
- 決算日のデータは使っていない。「窓開け＋大商い」を好材料の目印として代用している。

注意は上と同じ（銘柄の選び方が今の時点、手数料・税なし、過去の結果は将来を保証しない）。試した方法が多いので、偶然良く見えたものが混じる可能性がある。

## 業種の強弱（fetch_sector.mjs / study5.mjs）

17業種のETF（NEXT FUNDS TOPIX-17シリーズ、1617〜1633）で業種の強弱を出し、成績と関係があるかを調べた。2026年11月16日。

**A. 強い業種は、その後も強いか**（上位3業種と下位3業種の、その後の騰落率の差）

| 順位を決める期間 → 持つ期間 | 前半（〜2021年） | 後半（2022年〜） |
|---|---|---|
| 過去5日 → 5日 | −0.56% | −0.32% |
| 過去20日 → 5日 | −0.39% | −0.18% |
| 過去20日 → 20日 | −0.15% | −0.35% |
| 過去60日 → 20日 | +0.04% | −0.26% |
| 過去120日 → 20日 | +0.08% | −0.44% |

強かった業種がその後も強い、という傾向は無かった。短い期間では、むしろ少し逆（強かった業種が翌週は弱め）だった。

**B. 買い候補を、強い業種の銘柄に絞ると良くなるか**（今のルールを通過した候補7,094回。1回の平均R）

| 業種の順位（過去20日） | 前半 | 後半 |
|---|---|---|
| 強い（1〜5位） | +0.06R | +0.26R |
| 中（6〜12位） | +0.03R | +0.23R |
| 弱い（13〜17位） | +0.16R | +0.06R |

前半は弱い業種のほうが良く、後半は強い業種のほうが良かった。順位を過去5日・60日で決めても、一貫した関係は無かった。

**結論: 業種の強弱は、買い候補の条件にも通知にも組み込まない。**

## 銘柄を約1,400に広げて確かめ直した（fetch_wide.mjs / study6.mjs）

2026年11月17日。これまでの検証は大型株を中心に約170銘柄だった。買える値段の株でも同じかを見るため、売買の多い東証の1,438銘柄・10年分で、好材料の窓開け（窓+2%・出来高2倍・高値引けの陽線 → 翌日の始値で買い、損切り ATR×2、40営業日）をやり直した。その時点の売買代金が5,000万円未満の日は外した。

| | 前半（〜2021年） | 後半（2022年〜） |
|---|---|---|
| 基準: いつでも買う | +0.04%（約10万回） | +1.39%（約14万回） |
| 好材料の窓開け | +0.03%（3,791回） | +1.20%（5,544回） |

### わかったこと

1. **好材料の窓開けは、銘柄を広げると基準と変わらなかった。** 約170銘柄で見えていた「1回あたり約1%の上乗せ」は、広い銘柄では再現しなかった。窓開けを買い候補に使う根拠は弱くなった。追跡は続けるが、「効く」とは言わない。
2. **上げたあとの窓開けは悪い。** 直前20日で10%以上上げていた株の窓開けは、前半 −0.97%・後半 +0.02% で、どちらも基準（+0.38%・+1.03%）を下回った（943回・1,358回）。「すでに上がっている株の好材料」は見送る理由になる。
3. **下げたあとの窓開けは良く見えるが、まだ採用できない。** 直前20日で10%以上下げたあとの窓開けは、前半 +2.40%・後半 +4.42%。同じ条件で窓開けでない日（+1.46%・+2.23%）も上回った。窓が4%以上のものに限ると +4.6%・+7.0%。ただし:
   - 年ごとに見ると、同じ条件の基準に勝ったのは 2020・2022・2024・2025年の4年、負けたのは 2019・2023・2026年の3年。2026年は −2.64%。
   - 2024年だけで267回あり、8月の急落のあとの数日に集中している。相場全体が急落して戻した時期の影響が大きい。
   - 株価3,000円以上、売買代金10億円以上では弱い。良かったのは小さくて安い株で、買いにくい・売りにくい株ほど成績が良く出ている。
4. **「下げた株を買う」こと自体が良く見えるのは、銘柄の選び方のせいかもしれない。** 対象は「今の時点で売買が多い銘柄」。下げたまま消えた株・売買が細った株は入っていない。下げたあとに戻した株だけが残っているので、逆張りの成績は実際より良く出る。300円未満の株の基準が前半・後半とも +2.7% と高いのも、同じ理由と考えられる。**これを根拠に、下がっている株を買ってはいけない。**

### いまの結論

- 過去の日足だけから、「これを買えば勝てる」と言える買い方は、広い銘柄で確かめても見つかっていない。
- 一貫していたのは「避けるもの」のほう: 上げたあとの窓開け、値動きの荒い地合い、急騰への飛びつき。
- 次に試すなら: (1) 上場廃止の株も含むデータで逆張りを確かめる（手元では取れない）、(2) 決算の中身（上方修正・増益率）と株価の反応を組み合わせる（決算のデータが要る）、(3)「下げたあとの窓開け」を買い候補とは別枠で追跡して、実際の成績を見る。

## 決算・業績修正の見出しと、その後の株価（fetch_kessan.mjs / study7.mjs）

2026年11月17日。株価の形では優位が見つからなかったので、決算の中身を調べた。

- データ: 株探の銘柄ニュース（決算カテゴリ）の見出しと発表時刻。1,438銘柄、2025年1月〜2026年11月の 11,296件。**無料で見えるのは1銘柄あたり直近8件ほど（約2年ぶん）だけ。** それより前は、日付ごとの一覧（`/news/?category=3&date=YYYYMMDD`）で見出しが途中で切れていて、上方・下方の区別がつかない。
- 買い方: 発表の次の営業日の始値で買う（場中の発表でも引け後の発表でも、反応を見たあとに買える最初の値段）。
- 見出しの分類: 上方修正／下方修正／良い決算（増益・最高益・黒字浮上など）／悪い決算（減益・赤字）／その他（配当の修正など）。

| | 回数 | 5日 | 20日 | 40日 | 損切りつき40日 |
|---|---|---|---|---|---|
| 基準（いつでも買う） | 約12万 | +0.45% | +2.08% | +4.54% | +2.35% |
| 上方修正 | 2,278 | +1.14% | +2.10% | +3.55% | +1.42% |
| 良い決算 | 5,306 | +0.48% | +1.29% | +2.38% | +1.14% |
| 悪い決算 | 2,734 | +0.61% | +1.90% | +2.80% | +1.69% |
| 下方修正 | 673 | +0.17% | +1.20% | +2.63% | +1.58% |

### わかったこと

1. **決算が良かった株を翌日に買っても、長く持つ成績は基準より良くならない。** 上方修正も良い決算も、20日・40日では基準と同じか下。上方修正と下方修正の差もほとんど無い。良し悪しは、翌日の始値までに株価に織り込まれている。
2. **上方修正の直後の5日間だけ、基準より少し良い。** +1.14% 対 +0.45%。決算の時期ごとに見ると、8期のうち6期で基準を上回り、2期はほぼ同じ。差は約0.7%で、売買の値段のずれで消える程度。
3. **上方修正で最初に大きく上げた株（+12%以上）は、その後5日も上がりやすい。** 5日で +4.3%（270回）。8期のうち6期で基準を上回った。ただし1期あたり9〜51回と少なく、勝率は約3割で、少数の大きな上げに頼っている。値動きの荒い株が多く、朝の「危険度」では高に入る株と重なる。**まだ買う根拠にはできない。**
4. 修正の大きさ（%）が大きいほど良い、という関係は無かった。40%以上の上方修正は、むしろ損切りつき40日でマイナス。
5. 上方修正でも、直前20日に10%以上下げていた株は悪かった（損切りつき40日 −2.9%）。「下げたあとの好材料」は、窓開けの検証では良く見えたが、ここでは逆。どちらも当てにしない。

### 注意

- 期間が約2年しかなく、2025〜26年は相場全体が上がった時期（基準が40日で +4.5%）。長い期間では確かめられていない。
- 対象は今も売買が多い銘柄だけ。
- 見出しの言葉で分けただけで、会社予想との差や市場の予想との差は見ていない。

### これから

毎日の決算・業績修正の見出しを `node .claude/scripts/kabu-lens.mjs --kessan [YYYYMMDD]` で取れるようにした（分類つき）。夜の点検でためていけば、(a) 上方修正の直後5日、(b) 最初に大きく反応した上方修正、の2つを実際の成績で確かめられる。夜の指示文にはまだ組み込んでいない。

## 年度の業績の増減と、本決算のあとの株価（IR BANK、約10年。fetch_irbank.mjs / study8.mjs）

2026年11月17日。株探では約2年ぶんしか取れなかった決算の検証を、IR BANK の年度ごとの営業利益（実績）で約10年に広げた。

- データ: 498銘柄、2017〜2026年の本決算 3,794件。年度の営業利益を前の年度と比べて分類した（決算期を変えた年は除く）。
- 買い方: 本決算の発表日は取れなかったので、「決算期末から47日後（発表の期限45日をすぎたころ）の最初の営業日の始値」で買う。
- 比べ方: 同じ日に買った全銘柄の平均との差（超過）。相場全体の上げ下げを取り除くため。

| 分類 | 前半（〜2021年6月） 超過40日 | 後半 超過40日 |
|---|---|---|
| 増益30%以上 | −0.61%（343件） | −0.07%（645件） |
| 増益10〜30% | +0.69%（334件） | −0.61%（437件） |
| 増益0〜10% | −0.86% | +0.63% |
| 減益0〜20% | −0.22% | −0.13% |
| 減益20%以上 | +0.09% | −0.26% |
| 黒字転換 | −8.02%（31件） | −1.45%（77件） |

### わかったこと

1. **年度の業績が良かったか悪かったかは、本決算のあとの株価と関係が無かった。** どの分類も、前半・後半で向きが一致せず、差は±1%以内。年ごとに見ても、良い決算が悪い決算を上回った年と下回った年がほぼ半々。
2. 赤字縮小・赤字拡大は大きなプラスに見えるが（+7〜13%）、1期あたり18〜40件と少なく、値動きの荒い株の少数の大きな上げによる。対象が「今も売買が多い株」だけなので、赤字のまま消えた株が抜けている影響も大きい。使えない。
3. 株探の2年ぶんの検証（良い決算・上方修正は長く持つと基準と同じ）と合わせて、**決算の良し悪しは、発表のあとすぐ株価に織り込まれ、そのあとの上乗せは無い**と考えてよい。

### 注意

- 発表日そのものではなく、期限のあとに買っている。発表の直後の数日の動きは見ていない（それは上方修正の追跡で毎日確かめている）。
- 年度の数字だけで、四半期・会社予想・市場の予想との差は見ていない。
